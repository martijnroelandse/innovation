FROM PREPRINT TO PUBLICATION

You read one version.
What changed in the next?

Compare two versions of a research paper. Find passages with changed numbers, claim wording or methods—and inspect the evidence before deciding what matters.

The problem

A link to a published paper tells you where it ended up. It does not tell you whether the text you relied on changed.

The workflow

Select a matched pair, retrieve the available text, then inspect before and after passages. You can also import two versions yourself.

The boundary

DeltaX identifies textual changes. It does not decide which version is correct or infer that peer review caused a change.

PDF, JATS XML and plain text stay in this browser. PDF extraction loads Mozilla PDF.js from jsDelivr when first needed; no PDF is sent there. Scanned PDFs requiring OCR are not supported. Imported or pasted sources are labelled as user-supplied; their identity is not authenticated.

When pasting plain text, use blank lines between paragraphs. Optional section headings such as “Abstract”, “Results” and “Methods” help alignment. Select “User-supplied excerpts” below for pasted material.
